Tailscale 账号

自动登录（auth key）：

tailproxy 的每个出口都是一台独立的 Tailscale 设备。保存一个 可重复使用 的 auth key 后，新增的出口会自动加入 tailnet，不用逐个点授权链接；正在等待登录的节点也会立即用它登录。key 保存在状态目录的 tailscale.authkey（权限 600），面板里只显示开头几个字符。

在 Tailscale 管理后台创建 auth key（勾选 Reusable；建议同时勾选 Pre-approved）

#匹配条件目标

每个条件框一行一个值（也可以用逗号或空格分隔）。同一条规则里，域名类条件和 IP 段之间是「或」，端口是「且」。保存后写回配置文件的 rules: 段，文件其余部分保持不变，旧文件另存为 .bak。

当前生效的配置
