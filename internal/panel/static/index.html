登录 tailproxy 面板

执行 tailproxy start 时，终端会打印访问令牌和一键登录链接；之后随时可以用 tailproxy token 查看。打开一键登录链接即可自动登录，也可以把令牌粘贴到下面。如果设置了 panel.auth_token_env，令牌就是该环境变量的值。

出口

每个槽位是一个独立的 tailnet 设备（主机名 tailproxy-<名称>），固定使用一个出口节点。没有配置 auth key 时，需要打开登录链接把它加入你的 tailnet。

规则测试

输入域名和/或 IP，查看会命中哪条规则、走哪个出口。结果来自正在运行的规则引擎。

规则列表（按顺序首条命中）

#匹配条件目标

每个条件框一行一个值（也可以用逗号或空格分隔）。同一条规则里，域名类条件和 IP 段之间是「或」，端口是「且」。保存后写回配置文件的 rules: 段，文件其余部分保持不变，旧文件另存为 .bak。

当前生效的配置

配置里只保存环境变量名，不包含密钥本身。
